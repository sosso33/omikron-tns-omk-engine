## 2. What each handler says — and where the issue text was wrong

Every arm in `interp.cpp` names its handler; this is the evidence behind the five
readings that differ from `todo/iam-script-engine.md`. Handler blocks are
`clean/_vmhandlers.json` at the address `clean/_vmsummary.json` gives the opcode
(**the issue's addresses for 75, 69 and 93 — 0x40ACB0, 0x40AC40, 0x404840 — are inside
the blocks, not their entries: 0x40AC90, 0x40AC20, 0x404790**; the blocks for 49, 50 and
51 are polluted with the preceding function's jump tables and tails, CLAUDE.md 1's
trap, and the handler starts at the `push` run after them).

### 2a. `sub_41A140` is `Actor_ReleaseObject(index, remove)`, not `Actor_SetState`

Issue 34 reads op 69 as `Actor_SetState(actor, 0)`. `readable/src/04_sys.c` names
0x0041A140 `Actor_ReleaseObject(a1, a2)`: it unlinks the object slot the live actor
record links at `+41*4`, and the second argument chooses between **re-parenting the
node to the world at the slot's stored placement** (`a2 == 0`: the prop is dropped
where it was) and **freeing it** (`a2 == 1`: `sub_418DC0(4, slot)`, `o3de_FreeScene`).
So 69 and 68's found arm DROP, and 68's not-found arm REMOVES:

```
op 68 (0x40AAF0)                                  op 69 (0x40AC20)
  call sub_419E00        ; Actor_Player               call sub_40D760   ; Scene_FindObjectIndexById
  call sub_41A350        ; Actor_HeldObjectSlot       call sub_41A350   ; Actor_HeldObjectSlot
  cmp  ebx, -1 ; jz end                              cmp  eax, -1 ; jz end
  ... prop record by SLOT (below) ...                push 0 ; push esi
  found & state bit 0:                               call sub_41A140   ; Actor_ReleaseObject(idx, DROP)
    push 0 ; push ebp ; call sub_41A140  ; DROP      call sub_40B190   ; Actor_FindById(id)
    and edi, ~2 ; call sub_40AFC0        ; state &= ~2   mov word ptr [eax+10Eh], 0FFFFh
    call sub_41CC20                      ; Object_HideFromScene
  else:
    mov word_4E6CA0[ebx*2], 0FFFFh
    push 1 ; push ebp ; call sub_41A140  ; REMOVE
  call sub_40AEE0 ; call sub_40B190 ; mov word ptr [eax+10Eh], 0FFFFh
```

### 2b. The AREA prop table is at `+44`/`+74`, not `+8`; 68 matches the SLOT at `+0`

Issue 30 says "the resident AREA's `+8` array". All three handlers that walk it read
`Area_Block(area)` then **`mov edx, [eax+2Ch]` / `movsx eax, word ptr [eax+4Ah]`** —
+44 and +74, which is what `docs/FILE_FORMATS.md` "the prop table" already says — then
`Area_GetLoadedScene` → `Scene_Block` → `[eax+0Ch]` / `[eax+2Ah]` (+12 / +42). And
the field compared differs: 67 and 76 hold an OBJECTS id and compare
`movsx ebx, word ptr [edx+2]`; **68 holds the player's SLOT and compares
`movsx edi, word ptr [edx]`** — the record's `+0`, the runtime slot `Scene_LoadProps`
writes there. A port that matched 68 by id would release the wrong prop whenever two
records share an id, and never notice on a still frame.

### 2c. `inventory.remove_all 0, -1` can never remove anything

Op 52's `id == -1` arm (`loc_40A7D8`; **37 shipped sites, every one `0, -1`**) walks
the parallel 56-byte cache for entries whose `+0x24` bit 1 is set — that is the
`IAM\OBJECT` record's `+4` flag copied at cache `+32`, and `objects.h` names bit 1
"lost on reincarnation" — and then looks for the entry to remove with

```
loc_40A836:
    cmp     word ptr [ecx], 0FFFFh      ; the operand -1, constant-folded
    jz      short loc_40A849            ; -> remove at this index
    inc     eax ; add ecx, 2
    cmp     eax, esi                    ; esi = the stored count
    jl      short loc_40A836
    jmp     loc_40A8D9                  ; next entry
```

The compiler folded the opcode's own operand into the inlined find, so it searches
the first `count` ids for the TERMINATOR — which by construction sits at index
`count`, never inside. The removal at `loc_40A849` is unreachable. So the
reincarnation clean-out the scripts ask for 37 times **does nothing in the shipped
game**, and `GameState::listRemoveAll(list, -1)` (T6) returns 0 for the same reason
from the other side. Recorded rather than "fixed": the port reproduces the engine.

### 2d. `Actor_SetProperty`'s clamp is UNSIGNED: `-5` becomes 200

From `Runtime.exe.asm` at 0x0040B8D0, every 200-clamp is
`cmp esi, 0C8h ; jbe short …`, and Argent's is `cmp esi, 0FFFFh ; jbe` — `jbe`, not
`jle`. A script that subtracts damage past zero and writes it back through
`actor.stat.set` heals the actor to full. The port's `writeActorProperty` compares the
value as a `uint32_t`; `verify.py`'s probe asserts `-5 → 200` (§4, mutation 2 flips
it to a signed compare and the line reads −5).

### 2e. Op 93 writes on BOTH arms; the player's `+0xAA` is the HUD flash's argument

Issue 33 reads the player arm as `sub_41CE50(playerIndex, ?, field 2, value)` "on the
player record +0xAA". `sub_41CE50` is `Hud_ShowValue(index, property, value,
currentVie)` — 0x0041CE50 in `readable/src/04_sys.c`, which returns 0 for anyone but
the player and for properties 4 and 5 and otherwise starts the HUD flash — and
`movsx edx, word ptr [ecx+0AAh]` is the player record's **current Vie** passed as its
fourth argument, so the flash can show old against new. The write is the
`call sub_40B8D0` (`Actor_SetProperty`) that follows on both arms:

```
    call    sub_40E530          ; Var_Get(var)  -> esi
    cmp     edi, -1 ; jnz other
      call sub_419E00 ; Actor_Player
      movsx edx, word ptr [ecx+0AAh]   ; g_PlayerRecord + 170
      push edx ; push esi ; push ebp ; push eax
      call sub_41CE50           ; Hud_ShowValue(idx, prop, value, vie)
      jmp  both
    other:
      call sub_40D6A0           ; Scene_FindObjectRecord(slot, id) ; mov di, [eax]
    both:
      ... {prop, value, index} on the stack
      call sub_40B8D0           ; Actor_SetProperty
```

## 3. The design, and what is DB and what is hook

`Actor_FindById` (0x0040B190) opens

```c
result = g_PlayerRecord;                       // g_GameDB + 60
if (i16(g_PlayerRecord, 272) == a1 || a1 == -1) return result;
```

before it scans a chunk. So for the player — named `-1`, or by the id the DB record
carries at `+272` — the stat block, the held-object field (`+270`, DB `+330`) and the
identity are inside the 8192-byte block, and `player.become` writes `+272` there
(`rep movsd` of the whole record) while a save restores it. That makes
`Actor_IdBySlot(Actor_Player())` and DB `+332` the same number at every moment a
script could ask, so **91, and 86/93/67/68/69 on the player, run on `GameState`
alone with no hook** — 736 of 784 sites of 93 and 459 of 460 of 86. The hook
interface therefore has no `playerId()`; a Session that installs nothing still
gets the player's stats moved.

`WorldHooks` (`hooks.h`) is one virtual per engine function the handlers call
(`Actor_GetProperty`/`SetProperty` on a non-player record, the record's `+270`,
`Actor_HeldObjectSlot`, `word_4E6CA0[slot]` and its clear, `Actor_ReleaseObject`,
`Actor_HoldObject`, `Object_ShowInScene`/`HideFromScene`, the prop walk by slot and by
id, `object.place_at`), each defaulting to "no record / nothing", and **a null pointer
means stub, as before** for 75, 67, 68, 69, 76, 98 and for 86/93 on a non-player.

`props.h` is the pure half a Session calls on its resident chunk copies: the three
table walks (`findPropById` / `findPropBySlot` at +44/+74 and +12/+42;
`findCharacterRecord` at +40/+72 and +8/+40; `findActorRecord` at +56/+80 and
+24/+48), `readActorProperty` (the getter's 24 value cases), `writeActorProperty` (the
setter's 12 cases with the unsigned clamps and the `+260` ammunition array indexed by
the high word), and `+270`. `Session::actorRecord` in `area.cpp` is the duplicate of
`findActorRecord` and can be replaced by it when T11's rewrite lands (§6).

`setWorldWrites(false)` puts ALL twenty back on the stub recorder path. When on, the
recorded call carries the RESOLVED fields in the handler's own order, which is the
order `tables/vm_announce.json` indexes (49/50/51/52/67 field 1, 76 field 0, 93 field
2) — no shipped operand of any of these carries the indirect bit, so the recorded
fields are byte-for-byte what the raw path recorded.

### area.cpp

```cpp
// ---- the resident copies ------------------------------------------------
//
// Called where `loadArea` / `finishAreaTransition` / `reloadScene` settle the
// resident pair (T11: the slot's Area_TickLoad case 9). The AREA copy and the
// SCENE copy are the blocks `Area_Block` / `Scene_Block` return, and every
// per-record edit the handlers make lands in them.
void Session::loadProps() {
    unloadProps();
    areaCopy_.clear(); sceneCopy_.clear();
    if (curArea_ >= 0) {
        const auto areaFile = readFile(iam_ + "/AREA");
        const auto areas = IamArchive::open(areaFile);
        const auto ab = areas.chunk(static_cast<std::size_t>(curArea_));
        areaCopy_.assign(ab.begin(), ab.end());
    }
    const auto sc = sceneOverArea(state_, curArea_);
    if (sc != -1) {
        const auto sceneFile = readFile(iam_ + "/SCENE");
        const auto scenes = IamArchive::open(sceneFile);
        const auto sb = scenes.chunk(static_cast<std::size_t>(sc));
        sceneCopy_.assign(sb.begin(), sb.end());
    }
    // `Scene_LoadProps` (0x00409FC0): for every prop record whose state has
    // bit 0, the FIRST free entry of word_4E6CA0 (-1 when all 50 are taken)
    // takes the id and the record's +0 takes the slot; bit 1 links it into
    // the scene. AREA's table first, then the SCENE's.
    const auto walk = [&](std::vector<std::byte>& chunk, ChunkKind kind) {
        if (chunk.empty()) return;
        const std::size_t po = kind == ChunkKind::Area ? 44 : 12;
        const std::size_t co = kind == ChunkKind::Area ? 74 : 42;
        const std::span<const std::byte> b(chunk);
        if (b.size() < co + 2) return;
        const std::size_t p = u32at(b, po);
        const int n = i16at(b, co);
        if (n <= 0 || p + 24u * static_cast<std::size_t>(n) > b.size()) return;
        for (int i = 0; i < n; ++i) {
            const std::size_t o = p + 24u * static_cast<std::size_t>(i);
            const int id = i16at(b, o + 2), idx = i16at(b, o + 22);
            if (!(state_.propState(idx) & 1)) continue;
            int slot = -1;
            for (int k = 0; k < 50; ++k)
                if (objectSlotIds_[static_cast<std::size_t>(k)] == -1) { slot = k; break; }
            if (slot >= 0) objectSlotIds_[static_cast<std::size_t>(slot)] = id;
            chunk[o]     = static_cast<std::byte>(slot & 0xFF);
            chunk[o + 1] = static_cast<std::byte>((slot >> 8) & 0xFF);
            if (slot >= 0 && (state_.propState(idx) & 2)) shownSlots_.insert(slot);
        }
    };
    objectSlotIds_.fill(-1);
    walk(areaCopy_, ChunkKind::Area);
    walk(sceneCopy_, ChunkKind::Scene);
}

void Session::unloadProps() {
    objectSlotIds_.fill(-1);
    shownSlots_.clear();
    heldSlot_.clear();
}

// ---- the hooks ------------------------------------------------------------

std::span<std::byte> Session::Hooks::record(int actor) {
    if (auto o = findActorRecord(s_->areaCopy_, ChunkKind::Area, actor))
        return std::span<std::byte>(s_->areaCopy_).subspan(*o, kActorRecordSize);
    if (auto o = findActorRecord(s_->sceneCopy_, ChunkKind::Scene, actor))
        return std::span<std::byte>(s_->sceneCopy_).subspan(*o, kActorRecordSize);
    return {};
}

bool Session::Hooks::inObjectTable(int actor) const {
    return findCharacterRecord(s_->areaCopy_, ChunkKind::Area, actor).has_value() ||
           findCharacterRecord(s_->sceneCopy_, ChunkKind::Scene, actor).has_value();
}

bool Session::Hooks::getActorProperty(int actor, int property, std::int32_t& out) {
    if (!inObjectTable(actor)) return false;
    const auto r = record(actor);
    return !r.empty() && readActorProperty(r, property, out);
}

bool Session::Hooks::setActorProperty(int actor, int property, std::int32_t value) {
    if (!inObjectTable(actor)) return false;
    const auto r = record(actor);
    return !r.empty() && writeActorProperty(r, property, value);
}

int Session::Hooks::heldObjectField(int actor) {
    const auto r = record(actor);
    return r.empty() ? -1 : heldObjectOf(r);
}

void Session::Hooks::setHeldObjectField(int actor, int objectId) {
    const auto r = record(actor);
    if (!r.empty()) setHeldObjectOf(r, objectId);
}

int Session::Hooks::heldObjectSlot(int actor) {
    const auto it = s_->heldSlot_.find(actor);
    return it == s_->heldSlot_.end() ? -1 : it->second;
}

int Session::Hooks::objectIdInSlot(int slot) {
    return slot >= 0 && slot < 50 ? s_->objectSlotIds_[static_cast<std::size_t>(slot)] : -1;
}

void Session::Hooks::clearObjectSlot(int slot) {
    if (slot >= 0 && slot < 50) s_->objectSlotIds_[static_cast<std::size_t>(slot)] = -1;
}

// `Actor_ReleaseObject(index, remove)`: the slot leaves the hand. Dropped
// (remove false) it stays a scene object at its stored placement; removed it
// is freed - `sub_418DC0(4, slot)` - and leaves the shown set too.
void Session::Hooks::releaseObject(int actor, bool remove) {
    const auto it = s_->heldSlot_.find(actor);
    const int slot = it == s_->heldSlot_.end() ? -1 : it->second;
    if (it != s_->heldSlot_.end()) s_->heldSlot_.erase(it);
    if (remove && slot >= 0) s_->shownSlots_.erase(slot);
    s_->propEvents_.push_back({remove ? "remove" : "drop", actor, slot, -1});
}

void Session::Hooks::holdObject(int actor, int slot) {
    s_->heldSlot_[actor] = slot;
    s_->propEvents_.push_back({"hold", actor, slot, -1});
}

void Session::Hooks::showObject(int slot) {
    s_->shownSlots_.insert(slot);
    s_->propEvents_.push_back({"show", -1, slot, -1});
}

void Session::Hooks::hideObject(int slot) {
    s_->shownSlots_.erase(slot);
    s_->propEvents_.push_back({"hide", -1, slot, -1});
}

bool Session::Hooks::propBySlot(int slot, PropRef& out) {
    auto p = findPropBySlot(s_->areaCopy_, ChunkKind::Area, slot);
    if (!p) p = findPropBySlot(s_->sceneCopy_, ChunkKind::Scene, slot);
    if (!p) return false;
    out = {p->slot, p->id, p->stateIndex};
    return true;
}

bool Session::Hooks::propById(int id, PropRef& out) {
    auto p = findPropById(s_->areaCopy_, ChunkKind::Area, id);
    if (!p) p = findPropById(s_->sceneCopy_, ChunkKind::Scene, id);
    if (!p) return false;
    out = {p->slot, p->id, p->stateIndex};
    return true;
}

void Session::Hooks::placeObjectAt(int objectId, int address) {
    s_->propEvents_.push_back({"place", -1, objectId, address});
}
```
