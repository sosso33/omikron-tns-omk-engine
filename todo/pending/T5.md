## 1. What the engine does

`Dialog_TickUI` (0x0046A200) case 4, at the point it has the line's asset
name, stamps the phase global with one of three values:

```c
dword_9103DC = 2;
if (!strcmp(v48, a125338))     dword_9103DC = 7;   // "125338"
if (!memcmp(v4,  a02e19a, 7))  dword_9103DC = 8;   // "02E19A" and its NUL
```

The second test is **seven** bytes over a six-character literal, so the
terminator is compared and it is an exact match, not a prefix — `02E19AB`
does not match. The two literals differ in their first byte, so the missing
`else` cannot matter.

Case 2/7/8 is the whole of what those three states do, and it is one
condition:

```c
if ((a2 & 0x10) != 0
 || dword_9103DC == 7 && (a2 & 0xFFFFFFF3) != 0
 || dword_9103DC == 8 && Morph_IsDone())
{ Morph_Stop(); dword_9103DC = 3; }
```

state 3 being "the line is over", which walks on to the reply menu. Bits 4
and 8 are up and down — `Actors_TickAll` calls `Dialog_TickUI(2, dword_90E0E0
| dword_4E9718 & 0xC)`, which is why they reach the test at all — and they
are the pair the menu moves on, so state 7 excludes exactly them.
`Morph_IsDone` (0x0042CBD0) is the morph-finished flag `dword_4EA84C`, or a
5000 ms cap in its one fallback mode.

**Both assets ship, and each exactly once** — a scan of all 420 `IAM\DIALOG`
chunks with `tools/omkdialog.parse`: 321 conversations, 1174 nodes,

| state | asset | where | conversation |
|---|---|---|---|
| 7 `AnyKey` | `125338` | conversation 272, node 0 | `Kay'l / Intro` — the line a new game opens with |
| 8 `SelfEnding` | `02E19A` | conversation 186, node 0 | `Telis Demon/Toit  (Scene)` |
| 2 `Confirm` | the other 1172 | | |

Conversation 186 is **one node whose four `param` are all −1** — no branch at
all. So in the engine it opens, speaks for 7.51 s and closes with the player
touching nothing, which is what a line inside a cutscene has to do. The port
made it wait for a press for ever.

`02E19A` is already named elsewhere in the image for the same reason:
`Morph_Play` arms the blend with `sub_42BE10(1, strstr(path, "02E19A") == 0)`
— it is the one line cut without a blend-out (RECONSTRUCTION 2026-09-02).

## 2. What changed in the port

`engine/src/script/dialogue.h`

* new `enum class LineEnd { Confirm = 2, AnyKey = 7, SelfEnding = 8 }`,
  carrying the engine's own phase-global values, with the transcription above
  in its comment;
* `static LineEnd DialogPlayer::lineEndFor(const std::string& asset)` — the
  classifier as a free function, so a caller can ask about a name it has not
  opened and so the two literals can be tested against names the corpus does
  not contain;
* `lineState()`, `anyKeyCuts()`, `selfEnding()` — what a frontend reads;
* `kConfirmBit = 0x10`, `kMenuBits = 0x0C`, `kAnyKeyMask = 0xFFFFFFF3` — the
  input constants named rather than re-derived by each caller;
* `bool cutBy(std::uint32_t input) const` — the whole of case 2/7/8's
  condition for one input word;
* the class comment's "**it never advances itself**" now carries its
  exception, and `tick`'s comment says which state changes phase and why.

`engine/src/script/dialogue.cpp`

* `enter()` stamps `lineState_ = lineEndFor(voice_)` when the line starts —
  case 4's point in the machine;
* `cutBy` transcribes the three clauses; `lineOver()` stands in for
  `Morph_IsDone` because the port's clock for a line is its decoded voice;
* `tick` ends with `if (phase_ == Speaking && cutBy(0)) next();`. `cutBy(0)`
  is case 2/7/8 with no input word, which only a `SelfEnding` line can
  satisfy, so `Confirm` and `AnyKey` lines still wait — the rule that was
  right — and a state-8 line walks on through `next()` **unchanged**,
  including its rule that a lone unnamed continue branch advances straight
  through. One node per tick at most, the same as one press per frame.

`anyKeyCuts()` is exposed and nothing in this task consumes it: honouring it
is the viewer's half (T9 / a later frontend task), and until then a state-7
line is cut by confirm only, which is what it was before.

### Two behaviours left as they are, on purpose

* **A `SelfEnding` line whose `.3DM` will not load** has `lineLen_ == 0` and
  is therefore over on its first tick. That is one frame later than the
  engine, which sets state 3 inside case 4 when `Morph_Play` returns 0. No
  shipped line reaches it — `02E19A.3DM` is present, 866792 bytes.
* **`Morph_IsDone`'s 5000 ms fallback cap** (mode 1) is not modelled; the
  port always has the decoded voice length.

def c_engine_dialogue_line_states():
    r"""A line's END RULE is per-ASSET, and two shipped lines are not ordinary.

    `Dialog_TickUI` (0x0046A200) case 4 stamps the phase global from the line's
    asset name - `strcmp` against "125338" gives 7, a SEVEN-byte `memcmp`
    against "02E19A" (so the terminator too, an exact match) gives 8, anything
    else 2 - and case 2/7/8 is one condition over those three:

        if ((a2 & 0x10) != 0
         || dword_9103DC == 7 && (a2 & 0xFFFFFFF3) != 0
         || dword_9103DC == 8 && Morph_IsDone())
        { Morph_Stop(); dword_9103DC = 3; }

    So a **2** line is cut only by confirm; a **7** line by any input bit
    except 4 and 8, which are up and down and are the pair the reply menu moves
    on (they reach the test because `Actors_TickAll` passes
    `dword_90E0E0 | dword_4E9718 & 0xC`); and an **8** line ends BY ITSELF when
    the morph is done, with no press at all.

    **The port had none of it.** `DialogPlayer` waited for a press on every
    line, which is right for 1172 of the 1174 and hangs on the other two:
    conversation 186 - one node, all four `param` -1, the asset `02E19A` - is a
    conversation that in the engine opens, speaks for 7.51 s and closes without
    the player touching anything, and the port sat on it for ever.

    **Why the corpus scan is here and not just the two names.** "Two lines are
    special" is a claim about 1174 nodes, and this differences the port's
    classifier against `tools/omkdialog`'s own reader of `gamedata/IAM/DIALOG` -
    conversation count, node count, and WHERE each special line is - so the two
    literals are not merely quoted back. The `rule` row then tests the
    classifier on names the corpus does not contain, because one example of
    each cannot show what is *not* matched: `02E19AB` must be 2, and it is 8 if
    anyone re-reads the `memcmp` as a prefix test.

    **And the tick count is external.** `02E19A.3DM` is 7.5102 s by
    `tools/morph3dm.read`, so at 1/30 s a tick the line is over on tick
    `ceil(7.5102 * 30) = 226`; the port is asserted against that, not against
    its own number.
    """
    import tempfile, shutil, math
    eng = os.path.join(ROOT, "engine")
    fr  = omkpaths.data_root()
    if not os.path.isdir(eng):
        return ("skipped",), ("skipped",), "engine/ absent"
    b = subprocess.run(["make", "-s"], cwd=eng, capture_output=True, text=True)
    binp = os.path.join(eng, "build", "dialogue_probe")
    if b.returncode != 0 or not os.path.exists(binp):
        return ("build failed",), ("built",), "engine/ must build"
    ops = os.path.join(ROOT, "tables", "vm_opcodes.json")
    tmp = tempfile.mkdtemp()
    try:
        out = os.path.join(tmp, "d.txt")
        r = subprocess.run([binp, fr, ops, out], capture_output=True, text=True)
        if r.returncode != 0 or not os.path.exists(out):
            return ("probe failed",), ("ran",), "dialogue_probe must run"
        rows = {}
        for ln in open(out):
            f = ln.split()
            if f: rows[f[0]] = f[1:]
        if not {"scan", "state7", "self8", "rule"} <= set(rows):
            return tuple(sorted(rows)), ("scan", "self8", "state7", "rule"), \
                   "the probe must report all four rows"
        scan  = tuple(int(v) for v in rows["scan"])
        st7   = rows["state7"]
        # asset, state, anyKeyCuts, then cutBy for 0/4/8/C/10/1/20
        got7  = (st7[1], int(st7[2]), int(st7[3])) + \
                tuple(int(v) for v in st7[4:11])
        self8 = tuple(int(v) for v in rows["self8"])
        rule  = tuple(int(v) for v in rows["rule"])

        # ---- the same scan, off the FILE, with tools/omkdialog's own reader
        sys.path.insert(0, os.path.join(ROOT, "tools"))
        import omkdialog, morph3dm
        chunks = omkdialog.load_chunks()
        convs = nodes = 0
        ref7, ref8 = [], []
        for cid, blob in sorted(chunks.items()):
            p = omkdialog.parse(blob)
            if p is None: continue
            convs += 1
            for n in p[1]:
                nodes += 1
                if n["name"] == "125338": ref7.append((cid, n["index"]))
                if n["name"] == "02E19A": ref8.append((cid, n["index"]))
        if len(ref7) != 1 or len(ref8) != 1:
            return (len(ref7), len(ref8)), (1, 1), \
                   "one shipped line of each state - the check's premise"
        # the state-8 line's own length, and the tick it must end on
        pcm, _ch, _lay = morph3dm.read(os.path.join(fr, "MORPH", "02E19A.3DM"))
        secs = len(pcm) / 2.0 / 22050.0
        # `lineAt_` reaches k/30 after k ticks and `cutBy` tests AFTER the
        # increment, so the first tick with k/30 >= secs ends the line.
        wantTick = math.ceil(secs * 30)

        return (scan, got7,
                (self8[3], self8[5], self8[6], self8[7]),
                rule), \
               ((convs, nodes, nodes - 2, len(ref7), len(ref8),
                 ref7[0][0], ref7[0][1], ref8[0][0], ref8[0][1]),
                ("125338", 7, 1, 0, 0, 0, 0, 1, 1, 1),
                (wantTick, 2, 0, 1),
                (8, 7, 2, 2, 2, 2, 2, 2)), \
               "the SCAN (conversations, nodes, and how many lines end on " \
               "confirm / any key / by themselves, with where the last two " \
               "are), differenced against tools/omkdialog; then conversation " \
               "272's first line - its asset, its state, anyKeyCuts, and " \
               "whether input words 0/4/8/C/10/1/20 cut it (only 0x10 and the " \
               "bits outside 0xC may); then conversation 186 ticked with NO " \
               "PRESS - the tick it ends itself on (ceil of its own voice " \
               "length x 30, from tools/morph3dm), the phase it lands in " \
               "(2 = Finished), whether it is still playing, and how many " \
               "lines it played; then the classifier on eight names, six of " \
               "which the corpus does not contain"
    finally:
        shutil.rmtree(tmp, ignore_errors=True)
