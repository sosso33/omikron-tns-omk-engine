# Licensing

Two licences, because the two halves of OMK want different things.

| what | licence | file |
|---|---|---|
| **code** — `tools/`, `engine/`, `scripts/`, `tables/` | **GPL-3.0-or-later** | [`LICENSE`](LICENSE) |
| **prose** — `docs/`, `CLAUDE.md`, `README.md`, `todo/`, `transcript/` | **CC-BY-4.0** | [`docs/LICENSE`](docs/LICENSE) |

## Why they differ

The replica is a community reconstruction, and copyleft is the norm for that
(ScummVM, OpenMW, OpenRCT2 and OpenTTD are all GPL): it keeps a closed
commercial fork off the table. **GPL-3.0** rather than 2.0 for a concrete
reason as well as a philosophical one — the Vulkan loader is Apache-2.0, which
is incompatible with GPL-2.0 and fine with GPL-3.0, so 2.0 would have been a
trap the first time anyone shipped a build with the GPU backend linked in.

The findings are the opposite case. `docs/` is the part most worth quoting —
in a wiki, in another engine, in a tool with an incompatible licence — and
copyleft prose would block exactly that. **CC-BY-4.0** asks only for credit.
Creative Commons advises against CC licences for software, which is why the
split follows the code/prose line and not a directory boundary that happens to
be convenient.

`tables/` is code-side because it is generated by `tools/exetables.py` and
consumed by the replica, not read by people.

## What these licences do NOT cover

**They only license what OMK owns.** Nothing here grants any right in
*Omikron: The Nomad Soul* itself, which is © Quantic Dream / Eidos
Interactive. In particular:

* **the game data** (`gamedata/`) is yours to obtain, from your own disc or
  GOG install. It is not in this repository and never will be.
* **the disassembly** (`Runtime.exe.asm`, `Runtime.exe.c`) and everything
  mechanically derived from it (`clean/`, `readable/src/`) is a derivative
  work of the game's binary. Not distributed here, and putting a licence on
  this repository would not change that if it were.

A licence cannot launder provenance. That is the whole reason those two are
excluded rather than merely gitignored for size.

## Third-party components

Kept under their own terms, and **not** relicensed by anything above. None of
them conflicts with GPL-3.0.

| path | what | upstream | licence |
|---|---|---|---|
| `engine/third_party/pl_mpeg.h` | MPEG-1 / MP2 decoder and PS demuxer | [phoboslab/pl_mpeg](https://github.com/phoboslab/pl_mpeg) | **MIT** (Dominic Szablewski) |

That is the only third-party file in the published tree, and it is **vendored
deliberately** rather than found by the build: `docs/PORTING.md` A8 draws the
line as a vendored dependency being checked in so `make` works without it
installed, which makes a missing one a broken checkout, while a system
dependency's absence merely disables a frontend.

It does **not** carry an SPDX header from OMK, deliberately. Stamping
`GPL-3.0-or-later` on someone else's file is a false statement about its terms,
and it is the kind that survives a long time because it looks tidy.

## Contributions

Inbound = outbound: a contribution to code is offered under GPL-3.0-or-later,
and to prose under CC-BY-4.0. There is no CLA.

## Applying the headers

Source files carry an SPDX identifier so tooling can read the terms without
parsing this file:

```
// SPDX-License-Identifier: GPL-3.0-or-later
```

`verify.py: licence headers` asserts that every authored source file has one
and that no third-party file does.
